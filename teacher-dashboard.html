🐾 Husky Habitats · Teacher Dashboard

Make classroom questions and rewards, then generate a code for students. Review progress codes submitted through Google Forms.

This dashboard runs in your browser. It does not automatically sync to Google Sheets or student games. Keep the classroom code and progress submissions private.

📚 Classroom Update Builder

Students open 📚 Classroom Tools in Husky Habitats and paste this HC1- code. The game remembers it on that browser. A new code replaces the previous classroom question set; students keep their rooms and coins.

📊 Student Progress · Google Forms

Create a Google Form with a required paragraph question named Progress Code. Link the form to a Google Sheet. Students open 📚 Classroom Tools, click Copy Progress Code, and paste it into the form.
